# Justine Dupal Portfolio — GitHub Pages

This is a custom, zero-cost static portfolio. It has:
- a visual homepage with clickable project tiles
- category filters
- separate case-study pages
- Approach and About pages
- responsive mobile design
- no framework and no build step
- images rendered from the uploaded portfolio PDFs

## Publish in GitHub

1. Create a new PUBLIC GitHub repository named:
   `YOUR-GITHUB-USERNAME.github.io`
2. Upload EVERYTHING inside this folder to the repository root.
   `index.html` must be at the top level.
3. GitHub → repository → Settings → Pages.
4. Under "Build and deployment" select "Deploy from a branch".
5. Branch = `main`; folder = `/ (root)`; Save.
6. Wait 1–3 minutes.
7. Visit `https://YOUR-GITHUB-USERNAME.github.io`

## Important
Do NOT upload the ZIP itself. Upload the contents of the unzipped folder.

## Editing
- Homepage: `index.html`
- Styling: `styles.css`
- Filters: `script.js`
- About: `about.html`
- Approach: `approach.html`
- Case studies: `projects/*.html`
- Images: `assets/...`

## Content / positioning
The site deliberately does NOT pretend every project is an end-to-end product. It positions research, strategy, synthesis, decision-making, implementation, and evaluation as the work.

The architecture section includes:
- Boston Scientific Mobility Program
- Partners Healthcare / Mass General Brigham change-management work
The MGB page links to Gensler's current project page rather than copying Gensler imagery.

The client wall currently uses text wordmarks rather than third-party logo artwork. If you have approved logo files, you can replace the text cells with images later.
